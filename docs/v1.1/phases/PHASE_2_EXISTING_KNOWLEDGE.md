# Phase 2 Goal — Deepen Existing Model Knowledge

## Objective

Improve the quality of the three shipped model guides before expanding the catalog.

## Targets

- `openai-gpt-6-astra`
- `anthropic-claude-sonnet-5`
- `google-gemini-3-8-flash`

## Requirements

- re-open current first-party sources,
- add model-specific guidance only when sourceable,
- update verification metadata,
- keep model/harness boundaries intact,
- preserve concise practical prose,
- avoid unsupported rankings or benchmark claims.

## Stop condition

Each existing model entry should be materially more useful than V1 while remaining tightly sourced and maintainable.
