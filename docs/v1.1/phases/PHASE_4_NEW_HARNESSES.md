# Phase 4 Goal — Expand Harness Coverage

## Objective

Add independent coding harnesses that make the model-vs-harness distinction more useful.

## Primary targets

1. Cursor
2. GitHub Copilot CLI
3. OpenCode
4. Aider

## Requirements

For each harness:

- research first-party documentation,
- identify instruction/context behavior,
- identify tool/permission behavior where documented,
- record supported instruction files when appropriate,
- add scoped recommendations and cautions,
- keep model behavior out of the harness guide,
- validate schema/source metadata.

Implement and verify one harness at a time.

## Stop condition

All shipped V1.1 harness entries have meaningful harness-specific guidance and current sources.
