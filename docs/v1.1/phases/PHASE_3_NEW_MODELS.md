# Phase 3 Goal — Add New Model Entries

## Objective

Add a small number of genuinely useful model entries.

## Primary candidates

- GPT-5.3-Codex
- Claude Opus 5

## Mandatory precondition

Before creating files, verify from current first-party documentation:

- exact name/ID,
- current support/status,
- model-specific prompting material,
- enough distinct guidance to justify a separate entry.

If a candidate fails the precondition, do not ship it.

## Stop condition

Every new model entry is defensible as useful guidance rather than catalog filler.
